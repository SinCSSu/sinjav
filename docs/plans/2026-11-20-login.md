# 登录功能实现计划（Login）

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为 sinJav 增加单用户「用户名 + 密码」登录：Spring Security Session 保护全部 `/api/v1/**`，凭据存数据库（settings 表 BCrypt），首次未初始化走登录页初始化向导，设置页可改凭据，前端新增 `/login` 页 + 路由守卫 + 401 拦截。

**Architecture:** 后端引入 spring-boot-starter-security，`SecurityConfig` 放行 `/api/v1/auth/**` 与静态资源，其余 `/api/v1/**` 需认证；登录成功手动建立 Session（HttpSessionSecurityContextRepository，30 天 TTL，登录续期）。凭据以 `authUsername` / `authPasswordHash` 两个 key 存入现有 `settings` 表（无新迁移、无新表）。前端 `request()` 是 401 拦截唯一出口，登录态用 localStorage 标记 + 路由守卫。

**Tech Stack:** Spring Boot 4.1.2（Kotlin）+ Spring Security（Boot 4 对应 SS7）+ BCrypt；Vue 3 + Element Plus + hash router。

**已确认设计决策（grill-me 结论）：**
- 单用户 用户名+密码；保护全部 API（含图片/视频代理），`/api/v1/auth/**` 与静态资源放行
- Spring Security + Session；CSRF 关闭；Cookie `SameSite=Lax`、`max-age=30d`、30 天超时、登录续期
- 凭据存 DB（BCrypt 哈希）+ 设置页修改（需验证当前密码）
- 首次未初始化：登录页初始化向导，访问者自设凭据（仅无凭据时可调用，先到先得）
- 防爆破：全局连续 5 次失败锁 15 分钟（内存，重启清零）
- 不做记住我选项；401 用 ProblemDetail 兼容格式返回

```kotlin
package top.sincs.sinjav.config

import org.springframework.context.annotation.Bean
import org.springframework.context.annotation.Configuration
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity
import org.springframework.security.config.annotation.web.builders.HttpSecurity
import org.springframework.security.config.http.SessionCreationPolicy
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder
import org.springframework.security.crypto.password.PasswordEncoder
import org.springframework.security.web.SecurityFilterChain
import org.springframework.security.web.context.HttpSessionSecurityContextRepository
import org.springframework.security.web.context.SecurityContextRepository

/**
 * 登录安全配置（单用户）：
 * - 放行 /api/v1/auth/**（status/init/login/logout/credentials）与本地图片静态资源；
 * - 其余 /api/v1/** 需要登录会话，未登录返回 401（ProblemDetail 兼容格式，前端 request() 统一解析）；
 * - CSRF 关闭（同源 SPA + Session Cookie SameSite=Lax）；SPA 静态资源全部放行。
 */
@Configuration
@EnableWebSecurity
class SecurityConfig {

    @Bean
    fun securityFilterChain(http: HttpSecurity): SecurityFilterChain {
        http
            .csrf { it.disable() }
            .authorizeHttpRequests {
                it.requestMatchers("/api/v1/auth/**").permitAll()
                    .requestMatchers("/local-images/**").permitAll()
                    .requestMatchers("/api/v1/**").authenticated()
                    .anyRequest().permitAll()
            }
            .exceptionHandling {
                it.authenticationEntryPoint { _, response, _ ->
                    response.status = 401
                    response.contentType = "application/problem+json;charset=UTF-8"
                    response.writer.write(
                        """{"title":"Unauthorized","detail":"未登录或会话已过期","status":401}""",
                    )
                }
            }
            .sessionManagement { it.sessionCreationPolicy(SessionCreationPolicy.IF_REQUIRED) }
            .formLogin { it.disable() }
            .httpBasic { it.disable() }
            .securityContext {
                it.securityContextRepository(HttpSessionSecurityContextRepository())
            }
        return http.build()
    }

    @Bean
    fun passwordEncoder(): PasswordEncoder = BCryptPasswordEncoder()

    /** 登录控制器手动建立会话时使用的存储（与过滤器链一致） */
    @Bean
    fun securityContextRepository(): SecurityContextRepository = HttpSessionSecurityContextRepository()
}
```

注意：Spring Security 7 的 Kotlin lambda DSL 若与 6.x 写法有出入（编译报错时），以编译器提示为准做等价调整（如 `csrf(Customizer.withDefaults())` 风格）。

```kotlin
package top.sincs.sinjav.config

import org.springframework.jdbc.core.namedparam.NamedParameterJdbcTemplate
import org.springframework.security.crypto.password.PasswordEncoder
import org.springframework.stereotype.Service
import top.sincs.sinjav.common.AuthException
import java.time.Duration
import java.time.Instant
import java.util.concurrent.atomic.AtomicLong

/**
 * 单用户凭据存储与防爆破：
 * - 凭据存 settings 表（key=authUsername / authPasswordHash，BCrypt 哈希），不暴露于通用 Settings API；
 * - 防爆破：全局连续失败计数，连续 5 次失败锁定 15 分钟（内存实现，重启清零）。
 */
@Service
class AuthService(
    private val jdbc: NamedParameterJdbcTemplate,
    private val encoder: PasswordEncoder,
) {

    data class Credentials(val username: String, val passwordHash: String)

    companion object {
        private const val KEY_USERNAME = "authUsername"
        private const val KEY_PASSWORD_HASH = "authPasswordHash"
        private const val MAX_FAILURES = 5
        private val LOCK_DURATION: Duration = Duration.ofMinutes(15)
    }

    private val failCount = java.util.concurrent.atomic.AtomicInteger()
    private val lockedUntil = AtomicLong(0)

    fun load(): Credentials? {
        val rows = jdbc.query(
            "SELECT key, value FROM settings WHERE key IN (:k1, :k2)",
            mapOf("k1" to KEY_USERNAME, "k2" to KEY_PASSWORD_HASH),
        ) { rs, _ -> rs.getString("key") to rs.getString("value") }
            .toMap()
        val u = rows[KEY_USERNAME] ?: return null
        val h = rows[KEY_PASSWORD_HASH] ?: return null
        return Credentials(u, h)
    }

    fun initialized(): Boolean = load() != null

    /** 初始化凭据（仅库中无凭据时可用，先到先得；并发冲突返回 409） */
    fun init(username: String, password: String) {
        if (initialized()) throw AuthException(409, "账号已初始化，请直接登录")
        save(username, password)
    }

    /** 修改凭据：验证当前密码；用户名/新密码至少改一项 */
    fun updateCredentials(currentPassword: String, username: String?, newPassword: String?) {
        val cred = load() ?: throw AuthException(409, "账号尚未初始化")
        if (!encoder.matches(currentPassword, cred.passwordHash)) {
            throw IllegalArgumentException("当前密码不正确")
        }
        save(username ?: cred.username, newPassword ?: return)
    }

    fun verify(username: String, password: String): Boolean {
        val cred = load() ?: return false
        return cred.username == username && encoder.matches(password, cred.passwordHash)
    }

    /** 防爆破：锁定期间抛 429（剩余分钟数），登录成功后由调用方 resetFailures */
    fun checkLock() {
        val until = lockedUntil.get()
        if (until > 0 && Instant.now().toEpochMilli() < until) {
            val minutes = java.util.concurrent.TimeUnit.MILLISECONDS.toMinutes(until - Instant.now().toEpochMilli()) + 1
            throw AuthException(429, "失败次数过多，账号已临时锁定，请约 ${minutes} 分钟后再试")
        }
    }

    fun recordFailure() {
        if (failCount.incrementAndGet() >= MAX_FAILURES) {
            lockedUntil.set(Instant.now().plus(LOCK_DURATION).toEpochMilli())
            failCount.set(0)
        }
    }

    fun resetFailures() {
        failCount.set(0)
        lockedUntil.set(0)
    }

    private fun save(username: String, password: String) {
        upsert(KEY_USERNAME, username.trim())
        upsert(KEY_PASSWORD_HASH, encoder.encode(password))
    }

    private fun upsert(key: String, value: String) {
        jdbc.update(
            """
            INSERT INTO settings (key, value) VALUES (:k, :v)
            ON CONFLICT (key) DO UPDATE SET value = EXCLUDED.value, updated_at = CURRENT_TIMESTAMP
            """,
            mapOf("k" to key, "v" to value),
        )
    }
}
```

注意：settings 表 V1 迁移中两个方言定义一致（key PK + value + updated_at），`ON CONFLICT` 在 SQLite 3.24+ 与 PostgreSQL 均可用（SettingsService 已在用，直接复用同一写法）。

```kotlin
package top.sincs.sinjav.api

import jakarta.servlet.http.HttpServletRequest
import jakarta.servlet.http.HttpServletResponse
import jakarta.validation.Valid
import jakarta.validation.constraints.NotBlank
import jakarta.validation.constraints.Size
import org.springframework.http.HttpStatus
import org.springframework.http.ResponseEntity
import org.springframework.security.authentication.UsernamePasswordAuthenticationToken
import org.springframework.security.core.authority.SimpleGrantedAuthority
import org.springframework.security.core.context.SecurityContextHolder
import org.springframework.security.web.context.SecurityContextRepository
import org.springframework.validation.annotation.Validated
import org.springframework.web.bind.annotation.GetMapping
import org.springframework.web.bind.annotation.PostMapping
import org.springframework.web.bind.annotation.PutMapping
import org.springframework.web.bind.annotation.RequestBody
import org.springframework.web.bind.annotation.RequestMapping
import org.springframework.web.bind.annotation.RestController
import top.sincs.sinjav.common.AuthException
import top.sincs.sinjav.config.AuthService

@Validated
@RestController
@RequestMapping("/api/v1/auth")
class AuthController(
    private val auth: AuthService,
    private val securityContextRepository: SecurityContextRepository,
) {

    data class InitRequest(
        @field:NotBlank(message = "用户名必填")
        @field:Size(max = 64, message = "用户名过长")
        val username: String,
        @field:NotBlank(message = "密码必填")
        @field:Size(min = 6, max = 128, message = "密码长度需为 6-128 位")
        val password: String,
    )

    data class LoginRequest(
        @field:NotBlank(message = "用户名必填") val username: String,
        @field:NotBlank(message = "密码必填") val password: String,
    )

    data class CredentialsRequest(
        @field:NotBlank(message = "当前密码必填") val currentPassword: String,
        @field:Size(max = 64) val username: String?,
        @field:Size(min = 6, max = 128, message = "新密码长度需为 6-128 位") val newPassword: String?,
    )

    data class AuthStatus(val initialized: Boolean, val username: String?, val authenticated: Boolean)
    data class LoginResult(val username: String)

    /** 登录页/前端启动时调用：是否已初始化 + 当前登录态与用户名 */
    @GetMapping("/status")
    fun status(): AuthStatus {
        val cred = auth.load()
        val principal = SecurityContextHolder.getContext().authentication
        val loggedIn = principal != null && principal.isAuthenticated
            && principal !is org.springframework.security.core.userdetails.UserDetails
        return AuthStatus(
            initialized = cred != null,
            username = cred?.username,
            authenticated = loggedIn,
        )
    }

    /** 首次初始化（仅未初始化时可用），成功后自动登录 */
    @PostMapping("/init")
    fun init(@Valid @RequestBody req: InitRequest, request: HttpServletRequest, response: HttpServletResponse): LoginResult {
        auth.init(req.username, req.password)
        establishSession(req.username.trim(), request, response)
        return LoginResult(req.username.trim())
    }

    /** 登录：防爆破锁定 → 验证凭据 → 失败计数/成功重建会话（续期） */
    @PostMapping("/login")
    fun login(@Valid @RequestBody req: LoginRequest, request: HttpServletRequest, response: HttpServletResponse): LoginResult {
        auth.checkLock()
        if (!auth.verify(req.username.trim(), req.password)) {
            auth.recordFailure()
            throw AuthException(401, "用户名或密码错误")
        }
        auth.resetFailures()
        establishSession(req.username.trim(), request, response)
        return LoginResult(req.username.trim())
    }

    /** 退出登录：清上下文并销毁会话 */
    @PostMapping("/logout")
    fun logout(request: HttpServletRequest): ResponseEntity<Unit> {
        SecurityContextHolder.clearContext()
        request.getSession(false)?.invalidate()
        return ResponseEntity.status(HttpStatus.NO_CONTENT).build()
    }

    /** 修改用户名/密码（需验证当前密码），改密成功后保持当前会话 */
    @PutMapping("/credentials")
    fun updateCredentials(@Valid @RequestBody req: CredentialsRequest): LoginResult {
        if (req.username.isNullOrBlank() && req.newPassword.isNullOrBlank()) {
            throw IllegalArgumentException("用户名与新密码至少填一项")
        }
        auth.updateCredentials(req.currentPassword, req.username?.trim()?.ifBlank { null }, req.newPassword)
        return LoginResult(auth.load()?.username ?: req.username?.trim() ?: "")
    }

    /** 建立会话：先换新会话（防会话固定），再写入安全上下文，Cookie 30 天 TTL 由全局配置承载 */
    private fun establishSession(username: String, request: HttpServletRequest, response: HttpServletResponse) {
        val token = UsernamePasswordAuthenticationToken(
            username, null, listOf(SimpleGrantedAuthority("ROLE_USER")),
        )
        val context = SecurityContextHolder.createEmptyContext()
        context.authentication = token
        SecurityContextHolder.setContext(context)
        request.getSession(false)?.invalidate()
        request.session(true)
        securityContextRepository.saveContext(context, request, response)
    }
}
```

注意：`authenticated` 判断排除匿名标记与 UserDetails——本应用会话中的认证主体是 String（用户名），手动 token 满足该特征；SS7 编译如对 `principal is UserDetails` 有更简洁 API 再等价调整。

```kotlin
package top.sincs.sinjav

import org.junit.jupiter.api.Assertions.assertEquals
import org.junit.jupiter.api.Assertions.assertTrue
import org.junit.jupiter.api.Test
import org.springframework.beans.factory.annotation.Autowired
import org.springframework.boot.resttestclient.TestRestTemplate
import org.springframework.boot.resttestclient.autoconfigure.AutoConfigureTestRestTemplate
import org.springframework.boot.test.context.SpringBootTest
import org.springframework.boot.test.web.client.TestRestTemplateExtensions
import org.springframework.http.HttpEntity
import org.springframework.http.HttpHeaders
import org.springframework.http.HttpMethod
import org.springframework.http.HttpStatus
import org.springframework.http.MediaType
import org.springframework.test.context.DynamicPropertyRegistry
import org.springframework.test.context.DynamicPropertySource
import java.nio.file.Files
import java.nio.file.Path

/** 认证链路集成测试：初始化 → 登录 → 会话可用 → 登出 → 401；防爆破锁定；改凭据 */
@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
@AutoConfigureTestRestTemplate
class AuthFlowTests {

    companion object {
        private val dbFile: Path = Path.of("build", "sinjav-auth-test.db")

        @JvmStatic
        @DynamicPropertySource
        fun datasource(registry: DynamicPropertyRegistry) {
            Files.deleteIfExists(dbFile)
            registry.add("spring.datasource.url") { "jdbc:sqlite:${dbFile.toAbsolutePath()}" }
            registry.add("spring.datasource.hikari.data-source-properties.date_string_format") { "yyyy-MM-dd HH:mm:ss" }
        }
    }

    @Autowired
    lateinit var rest: TestRestTemplate

    private fun post(path: String, body: String, cookie: String? = null) =
        exchange(path, HttpMethod.POST, body, cookie)

    private fun exchange(path: String, method: HttpMethod, body: String?, cookie: String?) {
        val headers = HttpHeaders()
        headers.contentType = MediaType.APPLICATION_JSON
        cookie?.let { headers.add(HttpHeaders.COOKIE, it) }
        return rest.exchange(path, method, HttpEntity(body, headers), String::class.java)
    }

    private fun cookieOf(resp: org.springframework.http.ResponseEntity<String>): String? =
        resp.headers[HttpHeaders.SET_COOKIE]?.joinToString("; ") { it.split(";").first() }

    @Test
    fun `初始化-登录-受保护接口-登出-401`() {
        // 未初始化：受保护接口 401
        assertEquals(HttpStatus.UNAUTHORIZED, rest.getForEntity("/api/v1/movies", String::class.java).statusCode)
        // status：未初始化
        val status0 = rest.getForEntity("/api/v1/auth/status", Map::class.java).body!!
        assertEquals(false, status0["initialized"])
        // 初始化（弱密码被拒）
        assertEquals(HttpStatus.BAD_REQUEST, post("/api/v1/auth/init", """{"username":"admin","password":"123"}""").statusCode)
        val init = post("/api/v1/auth/init", """{"username":"admin","password":"secret66"}""")
        assertEquals(HttpStatus.OK, init.statusCode)
        val sessionCookie = cookieOf(init)
        assertTrue(sessionCookie != null && sessionCookie!!.isNotEmpty())
        // 重复初始化 409
        assertEquals(HttpStatus.CONFLICT, post("/api/v1/auth/init", """{"username":"a","password":"secret66"}""").statusCode)
        // 带会话访问受保护接口 200
        assertEquals(HttpStatus.OK, exchange("/api/v1/movies", HttpMethod.GET, null, sessionCookie).statusCode)
        // 登出后 401
        post("/api/v1/auth/logout", "", sessionCookie)
        assertEquals(HttpStatus.UNAUTHORIZED, exchange("/api/v1/movies", HttpMethod.GET, null, sessionCookie).statusCode)
    }

    @Test
    fun `登录失败5次触发锁定`() {
        val lockCred = """{"username":"admin","password":"secret66"}"""
        // 先确保已初始化（上一测试或本测试先跑都成立）
        val st = rest.getForEntity("/api/v1/auth/status", Map::class.java).body!!
        if (st["initialized"] != true) post("/api/v1/auth/init", lockCred)
        repeat(5) {
            val resp = post("/api/v1/auth/login", """{"username":"admin","password":"wrong-pass"}""")
            if (it < 4) assertEquals(HttpStatus.UNAUTHORIZED, resp.statusCode)
        }
        // 第 5 次失败后锁定：即使密码正确也 429
        assertEquals(HttpStatus.TOO_MANY_REQUESTS, post("/api/v1/auth/login", lockCred).statusCode)
    }

    @Test
    fun `验证当前密码后可改用户名`() {
        val st = rest.getForEntity("/api/v1/auth/status", Map::class.java).body!!
        if (st["initialized"] != true) post("/api/v1/auth/init", """{"username":"admin","password":"secret66"}""")
        // 当前密码错误 → 400
        val bad = post("/api/v1/auth/credentials", """{"currentPassword":"nope","username":"root"}""")
        assertEquals(HttpStatus.BAD_REQUEST, bad.statusCode)
        // 正确 → 200，status 显示新用户名
        val ok = post("/api/v1/auth/credentials", """{"currentPassword":"secret66","username":"root"}""")
        assertEquals(HttpStatus.OK, ok.statusCode)
        val status = rest.getForEntity("/api/v1/auth/status", Map::class.java).body!!
        assertEquals("root", status["username"])
    }
}
```

注意：锁定是全局内存计数，三个测试共享同一应用实例——`登录失败5次触发锁定` 会在结束时留下锁定状态，可能影响第三个测试的登录/改凭据（改凭据不走锁定检查，不受影响；但若测试顺序不同，第一个测试的登录可能被锁）。实现时如遇测试顺序问题：在锁定测试末尾等待解锁不可取，改为把 `checkLock`/锁定测试放到独立 `@SpringBootTest` 类（不同上下文缓存 key，可用不同 `spring.datasource.url` 已天然隔离，但安全计数器在同 JVM 同一 Bean——必须用独立上下文）。备用方案：锁定测试改用 `@DirtiesContext`。实现时以实际运行为准调整，保证三条链路断言不变。

## 风险与实现备注

1. **Spring Security 7（Boot 4.1.2）API 差异**：lambda DSL / entryPoint 写法如编译报错，按编译器提示做等价调整；`TestRestTemplate` 在 Boot 4 移至独立 artifact，其底层 RestTemplate 访问器名以实际 API 为准。
2. **测试间锁定状态共享**（同 JVM 同一 AuthService Bean）：防爆破计数是全局内存状态，AuthFlowTests 内多个测试可能互相影响锁定。实现时优先用 `@DirtiesContext` 或拆分上下文解决，断言语义保持不变。
3. **视频/图片代理**：`/api/v1/videos`、`/api/v1/images`（含 `<img src>` 与 `<video src>` 直连）带 Cookie 自动通过；`/local-images` 静态映射保持放行（无敏感元数据，仅本地图片文件）。
4. **settings 表复用**：凭据两行 key 不进 `SettingsUpdate`/`SettingsDto`，避免 `/settings` 接口泄露哈希。
